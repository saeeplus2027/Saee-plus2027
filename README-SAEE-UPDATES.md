# Saee Plus — تحديثات الواجهة

## التعديلات
- أصبحت نافذة تسجيل الدخول/إنشاء الحساب تظهر تلقائيًا عند فتح الموقع إذا لم توجد جلسة محلية صحيحة.
- أزيل خيار متابعة التصفح بدون حساب، ولا يمكن إغلاق نافذة الحساب قبل تسجيل الدخول.
- حدّثت ملاحظة الحساب لتوضيح أن الحسابات ما زالت محلية في هذا الإصدار.
- أضيف التحقق من معرض المشاريع (حتى 10 صور) إلى التحقق الخلفي في `lib/content-validation.js`.
- حدّث `lib/cms.ts` لرفع صور معرض المشروع إلى تخزين الصور (R2) بدل إرسال صور Base64 كبيرة مباشرة داخل قاعدة البيانات.

## تنبيه مهم بخصوص التزامن بين الأجهزة
هذه التعديلات وحدها لا تُفعّل المزامنة في موقع GitHub Pages المنشور؛ الملف `public/store.js` في المشروع ما زال يستخدم التخزين المحلي (`remote = false`). كما أن مسار API في مشروع Next/Vinext يعتمد حاليًا على مصادقة ChatGPT. لذلك يلزم تعديل/نشر Cloudflare Worker الفعلي وربط `public/store.js` به مع جلسات إدارة آمنة حتى تظهر تعديلات الإدارة على كل الأجهزة. لم أغيّر `remote` إلى `true` بشكل عشوائي حتى لا يتعطل الموقع أو تُفقد التعديلات.

## الملفات التي تغيرت
- `public/index.html`
- `lib/cms.ts`
- `lib/content-validation.js`
