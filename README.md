# سعي بلس — النسخة المباشرة

الموقع ولوحة الإدارة مرتبطان بحفظ مركزي: Cloudflare D1 للمحتوى وR2 للصور.
بعد الحفظ الناجح تظهر التعديلات في صفحات الزوار المفتوحة خلال نحو ثانيتين.

## الاستخدام

- افتح الموقع المنشور، ثم «إدارة الموقع»، أو افتح `/index.html#admin`.
- سجّل الدخول بحساب ChatGPT المالك للموقع. يتحقق الخادم من صلاحية المسؤول في كل عملية كتابة.
- عدّل ثم اضغط حفظ وانتظر رسالة التأكيد. لا حاجة لإعادة رفع الملفات.
- عند انقطاع الاتصال أو تعارض تعديلين، تظهر رسالة فشل ولا ندّعي نجاح الحفظ.
- يمكنك تنزيل نسخة JSON احتياطية واستيرادها. الاستيراد يغيّر الموقع المشترك بعد التأكيد.
- خيار ZIP داخل اللوحة ينزّل نسخة ثابتة منفصلة للعرض المحلي؛ لا يتصل بالموقع المباشر.

## استضافة هذا الكود

هذه النسخة تحتاج خادم Cloudflare Workers وتخزين D1 وR2 وتكامل مصادقة Sites.
لا يكفي فتح index.html أو رفع الملفات على GitHub Pages لتشغيل الحفظ المركزي.
المشروع مضبوط للنشر عبر Sites مع نفس هوية الموقع وصلاحياته السابقة.

- ملفات الواجهة: public/
- لوحة الإدارة: public/admin.js وpublic/admin.css
- API المحتوى: app/api/content/route.ts وlib/cms.ts
- API الصور: app/api/media/[key]/route.ts
- قاعدة البيانات ومخططها: db/schema.ts وdrizzle/
- إعدادات الربط: .openai/hosting.json
- متغير الخادم المطلوب: SAI_ADMIN_EMAIL (بريد المالك المتحقق منه؛ لا يُضمّن في الواجهة).
- التثبيت: pnpm install --frozen-lockfile
- توليد تغييرات قاعدة البيانات: pnpm db:generate
- البناء: pnpm build

للتطوير المحلي، اضبط متغير الخادم محليًا في .dev.vars (غير متتبع).
طبّق هجرات D1 على قاعدة التطوير قبل تجربة الحفظ. قواعد التطوير والنشر منفصلة.
لا تضف مفاتيح أو بيانات دخول إلى ملفات الواجهة.

تخزين localStorage يُستخدم للمفضلة ولذاكرة مؤقتة، ولا يُعد مصدر المحتوى في النسخة المباشرة.
تبقى لوحة الإدارة على حالتها أثناء التحرير لتجنب تبديل النماذج. تعديل متزامن من نافذة
أخرى يؤدي إلى رفض حفظ نسخة قديمة بدل الكتابة فوق تغييراتها.
