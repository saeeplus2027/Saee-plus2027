# سعي بلس — ميزات سعي الذكي

## تشغيل النسخة
ارفع محتويات مجلد public إلى استضافة ثابتة، أو ارفع المشروع كاملًا إلى GitHub وشغّل مسار العمل الموجود؛ فهو ينشر public مباشرةً. افتح index.html ثم زر «سعي الذكي»، أو index.html#smart. لا حاجة إلى تثبيت Node لتشغيل الواجهة الثابتة. ملفات الميزة: smart-engine.js وsmart-ui.js وsmart.css، مع الربط داخل index.html. احتفظ ببقية الملفات والأصول.

للتجربة محليًا من مجلد المشروع:

```sh
python3 -m http.server 8000 --directory public
```

افتح http://localhost:8000/index.html. لا يُنصح بفتح الملف ببروتوكول file لأن سلوك التخزين يختلف بين المتصفحات.

## ما تم تنفيذه
- توصيات قائمة على القواعد: اهتمامات اختيارية تشمل الكتب والخصومات والمشاريع والخدمات والتطوير والمشاريع التقنية. كل توصية تعرض سببها؛ قبل اختيار الاهتمامات تظهر اقتراحات عامة معلنة بوضوح.
- موافقة منفصلة غير مفعّلة مسبقًا لاستخدام فتح التفاصيل والحفظ في المفضلة. السجل محلي ومحدود بآخر 100 تفاعل. إلغاء الموافقة يمسحه. زر مستقل يمسح الاهتمامات والسجل. لا يُستورد سجل المفضلة السابق للتوصيات.
- حسابات محلية: لكل حساب ملف تفضيلات مستقل، وللزائر ملف منفصل. تسجيل الخروج يعيد ملف الزائر، وتغيير الحساب يمسح السؤال المعروض. لا مزامنة بين الأجهزة.
- بحث عربي يوحّد أشكال الحروف والأرقام ويستخدم مجموعات مرادفات ونوايا محددة. يعمل على التصنيف والعنوان والوصف والتفاصيل والشارة، ويشمل الأماكن المنشورة. البحث داخل الأقسام يستخدم المحرك نفسه.
- الميزانية الرقمية تُطبّق فقط على سعر منشور واضح بالدينار الأردني أو عنصر موصوف صراحة بالمجانية؛ سعر التبادل غير معروف ولا يعامل بصفر. نسبة الخصم ليست سعرًا. «بسعر مناسب» عامل ترتيب فقط ولا تثبت أن خدمة ما رخيصة. لا تحويل عملات.
- مساعد استرجاع محلي يعرض النصوص والأسعار المنشورة وبطاقات قابلة للمقارنة وروابط المصادر. عند غياب النتائج يصرح بعدم توفر المعلومات. لا يولد أسعارًا أو توافرًا ولا يؤكد جودة أو ساعات عمل فعلية. المحادثة الحالية في الذاكرة فقط، ولا تُحفظ الاستعلامات.
- قراءة أحدث SiteStore عند كل طلب؛ حذف أو إخفاء قسم يستبعده من نتائج البحث والتوصيات والمساعد. تحديث المحتوى يعيد عرض النتائج.
- زر سعي الذكي ظاهر في الموقع، مع مدخل بالصفحة الرئيسية ودعم الهاتف ولوحة المفاتيح.
- تحديث حزمة التصدير داخل الأدمن لتتضمن الميزات الجديدة.

## حدود النسخة الحالية
هذه بداية قائمة على قواعد وليست نموذجًا لغويًا أو بحث Embeddings أو محركًا هجينًا. نطاق فهم العربية هو المرادفات والقواعد داخل smart-engine.js؛ الاستعلامات المركبة أو اللهجات غير المعرفة قد تحتاج إعادة صياغة. المساعد لا يفسّر كل سؤال أو محادثة متعددة الأدوار. المقارنة تعرض البيانات فقط ولا تختار أفضل خدمة من حيث الجودة.

**مهم:** store.js المرفق يحدد remote=false؛ المحتوى والحسابات والتفضيلات في هذه النسخة محلية على المتصفح. حفظ الأدمن لا ينشر تغييره لجميع الزوار عبر GitHub Pages. الكود الخلفي الموجود في المشروع لا يتحول تلقائيًا إلى خدمة فعالة على الاستضافة الثابتة. هذه الإضافة لا تغيّر المصادقة أو توفر أمانًا إنتاجيًا للحسابات أو الإدارة. البيانات الأصلية تتضمن أمثلة توضيحية.

## التحقق
اختبارات المنطق:

```sh
node --test tests/smart.test.mjs
```

تغطي المرادفات العربية، الأرقام العربية والميزانية، استبعاد السعر المجهول، الكتب التقنية المجانية، شرح التوصية، منع استخدام التفاعلات دون الموافقة، استبعاد المحتوى المخفي والمحذوف، تحديث المحتوى، والإجابة الصريحة عند غياب المعلومة.

تحقق يدوي: افتح سعي الذكي، اختر اهتمامًا واحفظه، جرّب «مكان أدرس فيه بسعر مناسب»، ثم حدد ميزانية للتأكد من استبعاد الأماكن بلا سعر. فعّل الموافقة وافتح التفاصيل، ثم ألغها وتأكد من محو السجل. اطلب سعر خدمة غير منشورة من المساعد. اختبر حذف عنصر من الأدمن أثناء عرض النتائج.

## التطوير التالي
للبحث الدلالي: خدمة خلفية تبني فهرس embeddings من المحتوى العام وتحدثه مع الحفظ، ثم تعيد معرفات المصادر. للمساعد اللغوي: مفتاح على الخادم فقط، استرجاع مصادر منشورة، رفض الإجابات غير المسندة، واختبارات عربية للتقييم. لمحرك هجين: جمع تفاعلات بموافقة صريحة على الخادم وربطها بحسابات موثوقة، ثم تقييم جودة التوصيات قبل مزج درجات المحتوى والسلوك. لا توجد مفاتيح API في هذه النسخة ولا حاجة لاشتراك خارجي.

نتيجة التحقق الآلي: نجحت اختبارات المنطق السبعة وفحوص صياغة JavaScript. لم يكتمل الفحص البصري في متصفح؛ تعذر تنزيل Chromium في بيئة التنفيذ.

نجحت أيضًا اختبارات ربط DOM: فتح صفحة سعي الذكي، حفظ الاهتمامات، الموافقة وإلغاؤها، فتح المصادر، البحث، عدم اختراع إجابة، عرض مدخلات HTML كنص، عزل تفضيلات الحسابات، وتحديث النتائج عند إخفاء قسم. لم تسجل أخطاء JavaScript أثناء هذا الفحص.

عند تعديل ملفات الواجهة، أعد بناء حزمة التصدير بالأمر `python3 scripts/build-static-export.py` حتى تشمل نسخة ZIP المنزّلة من الأدمن آخر التعديلات.
