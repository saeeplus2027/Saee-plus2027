# سعي بلس — النسخة المرفقة مع سعي الذكي

هذه النسخة تستخدم تخزين المتصفح محليًا (store.js: remote=false).
ارفع محتويات public إلى GitHub Pages؛ مسار العمل في المشروع ينشر هذا المجلد مباشرة.
افتح index.html ثم زر «سعي الذكي» للتوصيات والبحث العربي والمساعد.

التوصيات والبحث والمساعد تعمل بقواعد وبيانات الموقع دون API خارجي.
اختر اهتماماتك في صفحة التوصيات. استخدام التفاعلات اختياري وغير مفعل مسبقًا.
إلغاء الموافقة يمسح سجل التفاعلات؛ زر المسح يمسح الاهتمامات والسجل.
التفضيلات منفصلة للحسابات المحلية وللزائر، ولا تتزامن بين الأجهزة.
المساعد ينقل المعلومات المنشورة فقط، ويصرح عند غياب المعلومة.
قد تتضمن البيانات أمثلة توضيحية؛ لا يؤكد المساعد الأسعار والتوفر الفعلي.

الحسابات ولوحة الإدارة في النسخة الحالية محلية وليست مصادقة إنتاجية.
حفظ الأدمن يغيّر محتوى المتصفح نفسه ولا ينشره تلقائيًا لكل الزوار.
استخدم تصدير ZIP في الإدارة ثم ارفع محتوياته لنشر تعديلات المحتوى.
الحفظ المركزي والمصادقة الآمنة يتطلبان إعداد خادم مستقل وتخزين وصلاحيات.

راجع SMART_FEATURES.md في جذر المشروع للتفاصيل والحدود والاختبارات.
